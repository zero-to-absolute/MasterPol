# Мастер пол

Настольное приложение для учёта партнёров производственной компании «Мастер пол». Учебный проект по практике, 2025.

## Что умеет

- вход по логину и паролю, у пользователя есть роль;
- список партнёров компании из базы данных;
- расчёт скидки партнёра;
- история продаж продукции партнёру;
- калькулятор расхода материала по типу продукции и типу материала.

## Технологии

C#, Windows Forms, .NET Framework 4.8, Microsoft SQL Server (ADO.NET, DataSet).

## Запуск

Открыть MasterPol.sln в Visual Studio. Строка подключения к базе находится в MasterPol/App.config, её нужно поменять на свой сервер SQL Server.
